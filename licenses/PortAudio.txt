Note (ToroidAMP-specific, RC-069-003B): sounddevice's own bundled
"portaudio-binaries" package includes prebuilt PortAudio DLLs for
several platforms and configurations, including optional ASIO-enabled
variants (`libportaudio*-asio.dll`). ToroidAMP's PyInstaller build
collects this bundle wholesale (via sounddevice's own standard
PyInstaller hook) rather than selecting only the specific Windows x64
default-host-API DLL actually used at runtime — the ASIO-enabled
variants are present in the distributed folder but never loaded or
used by ToroidAMP. The ASIO SDK itself (Steinberg Media Technologies
GmbH) is referenced by the portaudio-binaries project's own README as
the basis for those optional variants; ToroidAMP does not use or
license the ASIO SDK. See docs/release/RC_069_003_pyinstaller_onedir.md
for the general observation that this wholesale-bundle behavior is an
unoptimized packaging artifact, not a ToroidAMP feature.
