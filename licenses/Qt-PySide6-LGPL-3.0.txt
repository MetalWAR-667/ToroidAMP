Qt6 / PySide6 — LGPL-3.0-only

ToroidAMP obtains PySide6 and Qt6 through the official PyPI wheels
(pip install PySide6), whose own package metadata declares:

    License-Expression: LGPL-3.0-only OR GPL-2.0-only OR GPL-3.0-only

verified directly against the installed package's own METADATA file
(.venv/Lib/site-packages/pyside6-6.11.2.dist-info/METADATA) — not
assumed. ToroidAMP does not modify, statically link, or relink Qt in
any way; it dynamically links against Qt's shared libraries exactly as
PyInstaller's ONEDIR build already lays them out (separate DLL files
alongside ToroidAMP.exe, not merged into a single binary) — the
LGPL-3.0-only option is therefore the applicable choice for this
distribution, and is the one referenced by this file's name.
