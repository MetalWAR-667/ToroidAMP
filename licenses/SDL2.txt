Note (ToroidAMP-specific, RC-069-003B/RC-069-003C): pygame-ce also
bundles several SDL2 companion/helper libraries used for image, font,
and mixer support (SDL2_image, SDL2_mixer, SDL2_ttf) and their own
transitive codec dependencies. As of RC-069-003C, every one of these
helper/codec libraries actually present in the frozen ONEDIR
(dist/ToroidAMP/_internal/) has been individually inventoried and its
license verified from the component's own authoritative upstream
source, each with its own dedicated file in this directory:

  - FreeType-FTL.txt          (freetype.dll)
  - libpng.txt                (libpng16-16.dll)
  - libjpeg-IJG-and-BSD.txt   (libjpeg-62.dll)
  - libtiff.txt               (libtiff-5.dll)
  - libwebp-BSD-3-Clause.txt  (libwebp-7.dll, libwebpdemux-2.dll)
  - libogg-BSD-3-Clause.txt   (libogg-0.dll)
  - libopus-and-opusfile-BSD.txt (libopus-0.dll, libopusfile-0.dll)
  - WavPack-BSD-3-Clause.txt  (libwavpack-1.dll)
  - PortMidi.txt              (portmidi.dll — pygame's own bundled MIDI
    library, not an SDL/codec dependency, but inventoried alongside
    these during the same ONEDIR DLL walk)

None of them carry copyleft/LGPL-or-stronger terms — all are permissive
(zlib/libpng-style, BSD-2/3-Clause, IJG, or FreeType's FTL). None of
these MinGW-built DLLs carry an embedded Windows VERSIONINFO resource,
so an exact micro-version could not be extracted from the binaries
themselves; this does not affect license identification, which was
verified from each project's own current license file rather than
inferred from a version number.
