libxmp (Extended Module Player) — bundled via pygame-ce, version 4.6.3

Source verified 2026 against the upstream project (https://github.com/libxmp/libxmp)
and its release notes/issue tracker — not reproduced from memory. See
docs/release/RC_069_003B_license_and_docs.md for the full verification
trail (Copying file, README license section, issue #387 discussing the
4.6.1 LGPL-component removal, and third-party package listings).

libxmp went through a licensing transition: prior to version 4.6.1, the
full (non-"lite") library was overall LGPL because a handful of bundled
third-party components (an embedded unzip implementation, an LZW
depacker used by the Digital Symphony loader, and a few dead-code format
loaders) were LGPL-licensed. As of libxmp 4.6.1, upstream removed those
LGPL components. The version bundled by pygame-ce and used by ToroidAMP
is 4.6.3 (confirmed directly against the running DLL's own exported
`xmp_version`/`xmp_vercode` data symbols) — i.e. a version AFTER that
LGPL-component removal. The library's overall license for this version is
a permissive combination (0BSD AND BSD-3-Clause AND ISC AND MIT AND
Public Domain across its various source files), summarized by the
project's own README under the following MIT-style grant:
